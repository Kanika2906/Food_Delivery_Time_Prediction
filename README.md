# 🍔 Food Delivery Time Prediction using Linear Regression

A Machine Learning project that predicts **food delivery time** using **Linear Regression**. This project demonstrates the complete machine learning workflow, from data preprocessing to model evaluation, using Python and Scikit-learn.

## 📌 Project Overview

Food delivery platforms aim to provide accurate delivery estimates to improve customer satisfaction. In this project, a **Linear Regression** model is built to predict delivery time based on factors such as:

* 📍 Distance between restaurant and customer
* 🍳 Order preparation time
* 🚦 Traffic conditions
* 🕒 Time of the day
* 🛵 Delivery partner availability

The project covers the complete ML pipeline, including data cleaning, preprocessing, model training, evaluation, and prediction.

## 📂 Project Workflow

1. Load the dataset
2. Perform data cleaning
3. Exploratory Data Analysis (EDA)
4. Feature selection and preprocessing
5. Split data into training and testing sets
6. Train a Linear Regression model
7. Evaluate model performance
8. Make predictions on new data

---

## 📊 Model Evaluation

The model is evaluated using:

* R² Score
* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)

These metrics help measure how accurately the model predicts delivery time.
